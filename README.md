# Aprion TV

An independent Android TV player for public YouTube videos, with native Media3 playback, remote navigation, search, quality and audio-track controls. No account, analytics or ad SDK is included. This project is not affiliated with YouTube or Google.

Version **0.3.6-beta** (version code 10). Changes the theme Signed updates retain the existing package and permanent key. Physical-TV compatibility and audio/sync qualification remain limited. Captions are unsupported. Extraction can break when YouTube changes; ad-free playback is not guaranteed.

The app checks for and downloads updates while Home or Settings is open. Signed metadata and the APK must match the installed app's package, higher version and certificate. Android may require installation approval. Updates use the configured [Aprion TV repository](https://github.com/LocalCiggyShop/QuietScreen).

Playback uses a compact TV overlay with title/channel, pause/play, a progress bar, Settings and CC buttons, and a lazy row of on-device Recommended videos. A loading spinner appears while buffering. Left/Right browse buttons when controls are visible and seek ten seconds while hidden. OK or Up/Down reveals hidden controls; Down opens recommendations. Arrows navigate menu choices and the shelf; OK selects. Back hides all playback controls, including open menus; pressing Back again returns Home. Settings retains quality/audio selection; CC explains that captions are unavailable. Suggestions start only when selected, saving the outgoing resume position.

The browsing screen provides remote-controlled horizontal genre rows, pagination and focus restoration after playback. A Recommended row mixes preferred genres with discoveries using actual watch time, estimated completion and modest early-exit signals; all eight genre rows remain available. Diminishing returns prevent one long video from outweighing repeated enjoyable sessions. Search playback trains recognizable genres from the existing provider category or bounded title/channel words on-device; ambiguous videos are left unclassified. Recommendations refresh on return to Home without saving search queries. Settings can pause personalization or erase it. Continue watching appears second only when there are unfinished videos and resumes them at their saved position. Unfinished ordinary videos are saved after one second, including videos opened from Search; actual completion removes them.

Search and catalog results stay in memory. Eight bounded genre scores, playback/update settings and up to 24 unfinished video records (ID, title, channel, position, duration and detected or source genre) remain privately on-device, with Android backups disabled. The last 100 completed IDs keep recently finished videos out of Continue watching, including replays. Clear browsing session erases saved viewing records and completion IDs; Reset personalization separately erases genre scores. No database, server, account, telemetry or external recommender is used. Browsing sends fixed genre searches to YouTube; thumbnails/playback contact YouTube/CDNs and updates contact GitHub. Providers see normal request metadata and IP addresses. Saved records and genre scores are not uploaded; resuming requests the selected public video ID as ordinary playback does.
